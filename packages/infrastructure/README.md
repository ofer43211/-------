# Infrastructure Projects

This directory contains the following projects:

- **tailscale**: https://github.com/ofer43211/tailscale
- **firebaseui-web**: https://github.com/ofer43211/firebaseui-web
- **TheVortex_v4**: https://github.com/ofer43211/TheVortex_v4
- **echosync-v6**: https://github.com/ofer43211/echosync-v6

## Structure

Each project maintains its own:
- Dependencies (package.json)
- Build configuration
- Tests
- Documentation

## Development

To work on a specific project:
```bash
cd packages/infrastructure/<project-name>
npm install
npm run dev
```
